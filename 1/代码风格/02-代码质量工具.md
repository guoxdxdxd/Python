# 代码质量工具

## 1. 代码质量工具概述

代码质量工具是 Python 开发中不可或缺的辅助工具，它们帮助开发者保持代码的一致性、可读性和质量。

### 1.1 工具分类
- **格式化工具**：Black、autopep8
- **代码检查工具**：Flake8、Pylint、Pyflakes
- **类型检查工具**：MyPy、Pyright
- **导入排序工具**：isort
- **安全扫描工具**：Bandit、Safety
- **复杂度分析**：Radon、Xenon

### 1.2 工具选择建议
| 工具类型 | 推荐工具 | 特点 |
|----------|----------|------|
| 格式化 | Black | 无配置，一致性高 |
| 代码检查 | Flake8 | 轻量级，速度快 |
| 类型检查 | MyPy | 官方推荐，功能完整 |
| 导入排序 | isort | 与 Black 兼容 |
| 安全扫描 | Bandit | 专门的安全检查 |

## 2. Black - 代码格式化

### 2.1 安装和配置
```bash
# 安装 Black
pip install black

# 验证安装
black --version
```

### 2.2 基本使用
```bash
# 格式化单个文件
black myfile.py

# 格式化整个项目
black myproject/

# 检查格式（不修改文件）
black --check myfile.py

# 显示差异
black --diff myfile.py

# 显示详细输出
black --verbose myfile.py
```

### 2.3 配置选项
```bash
# 设置行长度
black --line-length 100 myfile.py

# 设置目标 Python 版本
black --target-version py311 myfile.py

# 包含/排除文件
black --include '\.pyi?$' myproject/
black --exclude '/(\.git|\.venv|build|dist)/' myproject/
```

### 2.4 配置文件
创建 `pyproject.toml`：
```toml
[tool.black]
line-length = 88
target-version = ['py311']
include = '\.pyi?$'
extend-exclude = '''
/(
  # directories
  \.eggs
  | \.git
  | \.hg
  | \.mypy_cache
  | \.tox
  | \.venv
  | build
  | dist
)/
'''
```

## 3. Flake8 - 代码检查

### 3.1 安装和配置
```bash
# 安装 Flake8
pip install flake8

# 安装插件
pip install flake8-docstrings
pip install flake8-import-order
pip install flake8-bugbear
```

### 3.2 基本使用
```bash
# 检查单个文件
flake8 myfile.py

# 检查整个项目
flake8 myproject/

# 显示统计信息
flake8 --statistics myfile.py

# 显示错误代码
flake8 --show-source myfile.py

# 忽略特定错误
flake8 --ignore=E501,W503 myfile.py
```

### 3.3 配置文件
创建 `.flake8`：
```ini
[flake8]
max-line-length = 88
extend-ignore = E203, W503
exclude =
    .git,
    __pycache__,
    .venv,
    venv,
    .eggs,
    *.egg,
    build,
    dist
per-file-ignores =
    __init__.py:F401
    tests/*:S101
```

### 3.4 常见错误代码
| 错误代码 | 说明 | 示例 |
|----------|------|------|
| E501 | 行太长 | 超过 88 字符 |
| E302 | 缺少空行 | 函数定义前缺少空行 |
| E305 | 缺少空行 | 类定义后缺少空行 |
| W503 | 操作符前换行 | `and` 前换行 |
| F401 | 未使用的导入 | `import os` 但未使用 |

## 4. MyPy - 类型检查

### 4.1 安装和配置
```bash
# 安装 MyPy
pip install mypy

# 验证安装
mypy --version
```

### 4.2 基本使用
```bash
# 检查单个文件
mypy myfile.py

# 检查整个项目
mypy myproject/

# 显示错误详情
mypy --show-error-codes myfile.py

# 生成 HTML 报告
mypy --html-report report/ myfile.py

# 实时检查
mypy --incremental myfile.py
```

### 4.3 类型注解示例
```python
from typing import List, Dict, Optional, Union

def greet(name: str) -> str:
    """返回问候语。"""
    return f"Hello, {name}!"

def process_numbers(numbers: List[int]) -> Dict[str, int]:
    """处理数字列表。"""
    return {
        "count": len(numbers),
        "sum": sum(numbers),
        "max": max(numbers) if numbers else 0
    }

def find_user(user_id: int) -> Optional[Dict[str, str]]:
    """查找用户。"""
    if user_id > 0:
        return {"id": str(user_id), "name": "张三"}
    return None

def calculate_area(length: Union[int, float], width: Union[int, float]) -> float:
    """计算面积。"""
    return float(length * width)
```

### 4.4 配置文件
创建 `mypy.ini`：
```ini
[mypy]
python_version = 3.11
warn_return_any = True
warn_unused_configs = True
disallow_untyped_defs = True
disallow_incomplete_defs = True
check_untyped_defs = True
disallow_untyped_decorators = True
no_implicit_optional = True
warn_redundant_casts = True
warn_unused_ignores = True
warn_no_return = True
warn_unreachable = True
strict_equality = True
```

## 5. isort - 导入排序

### 5.1 安装和配置
```bash
# 安装 isort
pip install isort

# 验证安装
isort --version
```

### 5.2 基本使用
```bash
# 排序导入
isort myfile.py

# 检查导入顺序
isort --check-only myfile.py

# 显示差异
isort --diff myfile.py

# 显示详细输出
isort --verbose myfile.py
```

### 5.3 配置选项
```bash
# 设置行长度
isort --line-length 88 myfile.py

# 设置多行输出模式
isort --multi-line 3 myfile.py

# 设置配置文件
isort --settings-file pyproject.toml myfile.py
```

### 5.4 配置文件
在 `pyproject.toml` 中：
```toml
[tool.isort]
profile = "black"
multi_line_output = 3
line_length = 88
include_trailing_comma = true
force_grid_wrap = 0
use_parentheses = true
ensure_newline_before_comments = true
```

## 6. Pylint - 代码分析

### 6.1 安装和配置
```bash
# 安装 Pylint
pip install pylint

# 验证安装
pylint --version
```

### 6.2 基本使用
```bash
# 分析单个文件
pylint myfile.py

# 分析整个项目
pylint myproject/

# 生成报告
pylint --output-format=json myfile.py

# 设置分数阈值
pylint --fail-under=8.0 myfile.py
```

### 6.3 配置文件
创建 `.pylintrc`：
```ini
[MASTER]
load-plugins=pylint.extensions.docparams

[MESSAGES CONTROL]
disable=missing-docstring,
        too-few-public-methods,
        too-many-arguments

[FORMAT]
max-line-length=88

[DESIGN]
max-args=5
max-locals=15
max-returns=6
max-branches=12
max-statements=50
```

## 7. Bandit - 安全扫描

### 7.1 安装和配置
```bash
# 安装 Bandit
pip install bandit

# 验证安装
bandit --version
```

### 7.2 基本使用
```bash
# 扫描单个文件
bandit myfile.py

# 扫描整个项目
bandit -r myproject/

# 生成报告
bandit -r myproject/ -f json -o report.json

# 设置严重级别
bandit -r myproject/ -ll
```

### 7.3 配置文件
创建 `.bandit`：
```ini
[bandit]
exclude_dirs = tests,venv,.venv
skips = B101,B601
```

## 8. 集成到开发流程

### 8.1 pre-commit 钩子
```bash
# 安装 pre-commit
pip install pre-commit

# 创建配置文件
cat > .pre-commit-config.yaml << EOF
repos:
  - repo: https://github.com/psf/black
    rev: 23.3.0
    hooks:
      - id: black
        language_version: python3.11

  - repo: https://github.com/pycqa/isort
    rev: 5.12.0
    hooks:
      - id: isort

  - repo: https://github.com/pycqa/flake8
    rev: 6.0.0
    hooks:
      - id: flake8

  - repo: https://github.com/pre-commit/mirrors-mypy
    rev: v1.3.0
    hooks:
      - id: mypy
        additional_dependencies: [types-requests]
EOF

# 安装钩子
pre-commit install

# 运行检查
pre-commit run --all-files
```

### 8.2 VS Code 配置
在 `.vscode/settings.json` 中：
```json
{
    "python.linting.enabled": true,
    "python.linting.flake8Enabled": true,
    "python.formatting.provider": "black",
    "python.formatting.blackArgs": ["--line-length", "88"],
    "editor.formatOnSave": true,
    "editor.codeActionsOnSave": {
        "source.organizeImports": true
    },
    "python.analysis.typeCheckingMode": "basic"
}
```

### 8.3 GitHub Actions
创建 `.github/workflows/quality.yml`：
```yaml
name: Code Quality

on: [push, pull_request]

jobs:
  quality:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.11'
    
    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install black flake8 mypy isort
    
    - name: Run Black
      run: black --check .
    
    - name: Run isort
      run: isort --check-only .
    
    - name: Run Flake8
      run: flake8 .
    
    - name: Run MyPy
      run: mypy .
```

## 9. 自动化脚本

### 9.1 质量检查脚本
```bash
#!/bin/bash
# quality_check.sh

echo "🔍 Running code quality checks..."

echo "1. Formatting with Black..."
if black --check .; then
    echo "✅ Black check passed"
else
    echo "❌ Black check failed"
    exit 1
fi

echo "2. Import sorting with isort..."
if isort --check-only .; then
    echo "✅ isort check passed"
else
    echo "❌ isort check failed"
    exit 1
fi

echo "3. Linting with Flake8..."
if flake8 .; then
    echo "✅ Flake8 check passed"
else
    echo "❌ Flake8 check failed"
    exit 1
fi

echo "4. Type checking with MyPy..."
if mypy .; then
    echo "✅ MyPy check passed"
else
    echo "❌ MyPy check failed"
    exit 1
fi

echo "🎉 All quality checks passed!"
```

### 9.2 自动修复脚本
```bash
#!/bin/bash
# fix_code.sh

echo "🔧 Fixing code issues..."

echo "1. Formatting with Black..."
black .

echo "2. Sorting imports with isort..."
isort .

echo "3. Running Flake8..."
flake8 .

echo "✅ Code fixes completed!"
```

## 11. 总结

代码质量工具是 Python 开发的重要辅助：

1. **Black**：自动格式化，保证代码一致性
2. **Flake8**：代码检查，发现潜在问题
3. **MyPy**：类型检查，提高代码安全性
4. **isort**：导入排序，保持代码整洁
5. **Pylint**：深度分析，提供改进建议
6. **Bandit**：安全扫描，发现安全漏洞

通过合理配置和使用这些工具，可以显著提高代码质量和开发效率。
