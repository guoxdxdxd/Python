# PEP 8 代码规范

## 1. PEP 8 简介

PEP 8（Python Enhancement Proposal 8）是 Python 官方推荐的代码风格指南，旨在提高代码的可读性和一致性。

### 1.1 PEP 8 的重要性
- **提高可读性**：统一的代码风格让代码更易理解
- **团队协作**：统一的规范便于团队开发
- **维护性**：规范的代码更容易维护和修改
- **专业性**：遵循标准体现专业素养

### 1.2 工具支持
- **Black**：自动代码格式化工具
- **Flake8**：代码风格检查工具
- **Pylint**：代码质量分析工具
- **isort**：导入语句排序工具

## 2. 代码布局

### 2.1 缩进
```python
# 使用 4 个空格进行缩进（推荐）
def function_name():
    if condition:
        do_something()
        if another_condition:
            do_another_thing()

# 不要使用制表符（Tab）
# 不要混用空格和制表符
```

### 2.2 行长度
```python
# 每行最多 79 个字符（推荐 88 个字符）
# 长行可以通过以下方式处理：

# 1. 使用括号
total = (first_variable + second_variable + 
         third_variable + fourth_variable)

# 2. 使用反斜杠
total = first_variable + second_variable + \
        third_variable + fourth_variable

# 3. 函数参数换行
def function_name(
    parameter_one,
    parameter_two,
    parameter_three,
    parameter_four
):
    pass
```

### 2.3 空行
```python
# 顶级函数和类定义之间使用两个空行
class FirstClass:
    pass


class SecondClass:
    pass


def top_level_function():
    pass


# 类内部方法之间使用一个空行
class MyClass:
    def first_method(self):
        pass

    def second_method(self):
        pass

# 函数内部逻辑分组之间使用空行
def complex_function():
    # 第一部分逻辑
    result = calculate_something()
    
    # 第二部分逻辑
    processed_result = process_result(result)
    
    return processed_result
```

## 3. 导入语句

### 3.1 导入顺序
```python
# 1. 标准库导入
import os
import sys
from datetime import datetime

# 2. 第三方库导入
import requests
import numpy as np
from flask import Flask

# 3. 本地应用/库导入
from myproject.models import User
from myproject.utils import helper_function

# 每组导入之间使用空行分隔
```

### 3.2 导入风格
```python
# 推荐：每个导入语句单独一行
import os
import sys

# 不推荐：多个导入在一行
import os, sys

# 推荐：从模块导入特定函数
from collections import defaultdict, Counter

# 推荐：使用别名
import numpy as np
import pandas as pd

# 避免：使用通配符导入
# from module import *  # 不推荐
```

## 4. 字符串

### 4.1 字符串引号
```python
# 使用单引号或双引号都可以，但要保持一致
message = 'Hello, World!'
name = "张三"

# 如果字符串包含引号，使用另一种引号
text = "He said 'Hello'"
text = 'He said "Hello"'

# 使用三引号处理多行字符串
long_text = """
这是一个很长的字符串
可以跨越多行
"""
```

### 4.2 字符串格式化
```python
# 推荐：使用 f-string（Python 3.6+）
name = "张三"
age = 25
message = f"姓名：{name}，年龄：{age}"

# 推荐：使用 .format() 方法
message = "姓名：{}，年龄：{}".format(name, age)

# 不推荐：使用 % 格式化
message = "姓名：%s，年龄：%d" % (name, age)
```

## 5. 表达式和语句

### 5.1 比较操作
```python
# 推荐：使用 is 和 is not 比较 None
if value is None:
    pass

if value is not None:
    pass

# 推荐：使用 == 和 != 比较值
if value == 0:
    pass

if value != 0:
    pass

# 推荐：使用 in 和 not in
if item in container:
    pass

if item not in container:
    pass
```

### 5.2 布尔值
```python
# 推荐：直接使用布尔值
if condition:
    pass

# 不推荐：与 True/False 比较
if condition == True:  # 不推荐
    pass

if condition == False:  # 不推荐
    pass

# 推荐：使用 not
if not condition:
    pass
```

### 5.3 异常处理
```python
# 推荐：使用具体的异常类型
try:
    result = risky_operation()
except ValueError as e:
    handle_error(e)

# 不推荐：使用裸露的 except
try:
    result = risky_operation()
except:  # 不推荐
    handle_error()

# 推荐：使用 finally 清理资源
try:
    result = risky_operation()
except ValueError as e:
    handle_error(e)
finally:
    cleanup_resources()
```

## 7. 注释

### 7.1 行内注释
```python
# 行内注释应该与代码至少间隔两个空格
x = x + 1  # 增加计数器

# 不推荐：注释与代码没有间隔
x = x + 1#增加计数器
```

### 7.2 块注释
```python
# 块注释应该与代码保持相同的缩进级别
def complex_function():
    # 这是一个复杂的函数
    # 它执行多个步骤
    # 1. 验证输入
    # 2. 处理数据
    # 3. 返回结果
    pass
```

### 7.3 文档字符串
```python
def calculate_area(length, width):
    """
    计算矩形的面积。
    
    Args:
        length (float): 矩形的长度
        width (float): 矩形的宽度
    
    Returns:
        float: 矩形的面积
    
    Raises:
        ValueError: 当长度或宽度为负数时
    """
    if length < 0 or width < 0:
        raise ValueError("长度和宽度必须为正数")
    return length * width
```

## 10. 工具使用

### 10.1 Black 格式化
```bash
# 安装 Black
pip install black

# 格式化文件
black myfile.py

# 格式化目录
black myproject/

# 检查格式（不修改文件）
black --check myfile.py
```

### 10.2 Flake8 检查
```bash
# 安装 Flake8
pip install flake8

# 检查文件
flake8 myfile.py

# 检查目录
flake8 myproject/

# 忽略特定错误
flake8 --ignore=E501,W503 myfile.py
```

### 10.3 isort 排序导入
```bash
# 安装 isort
pip install isort

# 排序导入
isort myfile.py

# 检查导入顺序
isort --check-only myfile.py
```

## 13. 总结

PEP 8 是 Python 开发的重要规范，遵循这些规范可以：

1. **提高代码质量**：统一的风格和规范
2. **增强可读性**：清晰的代码结构
3. **便于维护**：规范的代码更容易修改
4. **团队协作**：统一的开发标准

通过使用 Black、Flake8 等工具，可以自动化地检查和格式化代码，确保代码符合 PEP 8 规范。
