# 开发工具配置

## 1. VS Code 配置

### 1.1 安装和基础配置
1. 下载并安装 [VS Code](https://code.visualstudio.com/)
2. 安装 Python 扩展包：
   - Python（Microsoft）
   - Python Docstring Generator
   - Python Indent
   - Python Type Hint
   - Pylance

### 1.2 配置文件设置
创建或编辑 `settings.json`：
```json
{
    "python.defaultInterpreterPath": "./venv/bin/python",
    "python.terminal.activateEnvironment": true,
    "python.linting.enabled": true,
    "python.linting.pylintEnabled": false,
    "python.linting.flake8Enabled": true,
    "python.formatting.provider": "black",
    "python.formatting.blackArgs": ["--line-length", "88"],
    "editor.formatOnSave": true,
    "editor.codeActionsOnSave": {
        "source.organizeImports": true
    },
    "files.exclude": {
        "**/__pycache__": true,
        "**/*.pyc": true
    },
    "python.analysis.autoImportCompletions": true,
    "python.analysis.typeCheckingMode": "basic"
}
```

### 1.3 调试配置
创建 `.vscode/launch.json`：
```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Python: Current File",
            "type": "python",
            "request": "launch",
            "program": "${file}",
            "console": "integratedTerminal",
            "cwd": "${workspaceFolder}"
        },
        {
            "name": "Python: Module",
            "type": "python",
            "request": "launch",
            "module": "enter-your-module-name-here",
            "console": "integratedTerminal"
        }
    ]
}
```

### 1.4 任务配置
创建 `.vscode/tasks.json`：
```json
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "Run Tests",
            "type": "shell",
            "command": "python",
            "args": ["-m", "pytest"],
            "group": "test",
            "presentation": {
                "echo": true,
                "reveal": "always",
                "focus": false,
                "panel": "shared"
            }
        },
        {
            "label": "Format Code",
            "type": "shell",
            "command": "black",
            "args": ["."],
            "group": "build"
        }
    ]
}
```

## 2. PyCharm 配置

### 2.1 项目设置
1. 创建新项目时选择虚拟环境
2. 配置 Python 解释器：
   - File → Settings → Project → Python Interpreter
   - 选择虚拟环境中的 Python 解释器

### 2.2 代码风格设置
1. File → Settings → Editor → Code Style → Python
2. 设置缩进为 4 个空格
3. 设置行长度为 88 字符
4. 启用自动格式化

### 2.3 插件推荐
- Python Security
- Rainbow Brackets
- Key Promoter X
- GitToolBox
- Markdown Navigator

### 2.4 运行配置
1. Run → Edit Configurations
2. 添加 Python 配置：
   - Script path: 选择主文件
   - Working directory: 项目根目录
   - Environment variables: 添加必要的环境变量

## 3. Jupyter Notebook 配置

### 3.1 安装和启动
```bash
# 安装 Jupyter
pip install jupyter notebook

# 安装 JupyterLab（推荐）
pip install jupyterlab

# 启动 Jupyter
jupyter notebook

# 或启动 JupyterLab
jupyter lab
```

### 3.2 配置 Jupyter
创建 `~/.jupyter/jupyter_notebook_config.py`：
```python
c = get_config()

# 设置默认目录
c.NotebookApp.notebook_dir = '/path/to/your/projects'

# 自动打开浏览器
c.NotebookApp.open_browser = True

# 设置端口
c.NotebookApp.port = 8888

# 允许远程访问
c.NotebookApp.allow_remote_access = True

# 设置密码
c.NotebookApp.password = 'your-hashed-password'
```

### 3.3 扩展安装
```bash
# 安装 Jupyter 扩展
pip install jupyter_contrib_nbextensions
jupyter contrib nbextension install --user

# 安装 JupyterLab 扩展
pip install jupyterlab-git
pip install jupyterlab-lsp
```

## 4. 终端配置

### 4.1 iTerm2 配置（macOS）
1. 下载并安装 [iTerm2](https://iterm2.com/)
2. 安装 Oh My Zsh：
```bash
sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

3. 安装主题和插件：
```bash
# 安装 Powerlevel10k 主题
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k

# 安装插件
git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
git clone https://github.com/zsh-users/zsh-syntax-highlighting.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting
```

4. 配置 `.zshrc`：
```bash
ZSH_THEME="powerlevel10k/powerlevel10k"
plugins=(git python pip virtualenv zsh-autosuggestions zsh-syntax-highlighting)

# Python 相关别名
alias py="python"
alias py3="python3"
alias pip="pip3"
alias venv="python -m venv"
alias activate="source venv/bin/activate"
```

### 4.2 Windows Terminal 配置
1. 安装 [Windows Terminal](https://github.com/microsoft/terminal)
2. 安装 PowerShell 7：
```powershell
winget install Microsoft.PowerShell
```

3. 安装 Oh My Posh：
```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force; Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://ohmyposh.dev/install.ps1'))
```

4. 配置 PowerShell 配置文件：
```powershell
# 创建配置文件
New-Item -Path $PROFILE -Type File -Force

# 编辑配置文件
notepad $PROFILE

# 添加以下内容
oh-my-posh init pwsh --config "$env:POSH_THEMES_PATH\jandedobbeleer.omp.json" | Invoke-Expression
```

## 6. 包管理工具配置

### 6.1 pip 配置
创建 `~/.pip/pip.conf`（Linux/macOS）或 `%APPDATA%\pip\pip.ini`（Windows）：
```ini
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple
trusted-host = pypi.tuna.tsinghua.edu.cn
timeout = 120

[install]
user = true
```

### 6.2 Poetry 配置
```bash
# 安装 Poetry
curl -sSL https://install.python-poetry.org | python3 -

# 配置镜像源
poetry config repositories.aliyun https://mirrors.aliyun.com/pypi/simple/
poetry config repositories.tencent https://mirrors.cloud.tencent.com/pypi/simple/

# 设置虚拟环境路径
poetry config virtualenvs.in-project true
```

### 6.3 Conda 配置
```bash
# 添加镜像源
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge/

# 设置搜索时显示通道地址
conda config --set show_channel_urls yes
```

## 7. 代码质量工具配置

### 7.1 Black 配置
创建 `pyproject.toml`：
```toml
[tool.black]
line-length = 88
target-version = ['py311']
include = '\.pyi?$'
extend-exclude = '''
/(
  # directories
  \.eggs
  | \.git
  | \.hg
  | \.mypy_cache
  | \.tox
  | \.venv
  | build
  | dist
)/
'''
```

### 7.2 Flake8 配置
创建 `.flake8`：
```ini
[flake8]
max-line-length = 88
extend-ignore = E203, W503
exclude =
    .git,
    __pycache__,
    .venv,
    venv,
    .eggs,
    *.egg,
    build,
    dist
```

### 7.3 MyPy 配置
创建 `mypy.ini`：
```ini
[mypy]
python_version = 3.11
warn_return_any = True
warn_unused_configs = True
disallow_untyped_defs = True
disallow_incomplete_defs = True
check_untyped_defs = True
disallow_untyped_decorators = True
no_implicit_optional = True
warn_redundant_casts = True
warn_unused_ignores = True
warn_no_return = True
warn_unreachable = True
strict_equality = True
```

## 8. 测试工具配置

### 8.1 Pytest 配置
创建 `pytest.ini`：
```ini
[tool:pytest]
testpaths = tests
python_files = test_*.py
python_classes = Test*
python_functions = test_*
addopts = 
    -v
    --tb=short
    --strict-markers
    --disable-warnings
markers =
    slow: marks tests as slow
    integration: marks tests as integration tests
```

### 8.2 Coverage 配置
创建 `.coveragerc`：
```ini
[run]
source = src
omit = 
    */tests/*
    */venv/*
    */env/*

[report]
exclude_lines =
    pragma: no cover
    def __repr__
    raise AssertionError
    raise NotImplementedError
```

## 9. 环境变量管理

### 9.1 使用 python-decouple
```bash
# 安装
pip install python-decouple

# 创建 .env 文件
DATABASE_URL=postgresql://user:password@localhost/dbname
SECRET_KEY=your-secret-key

```

### 9.2 使用示例
```python
from decouple import config

DATABASE_URL = config('DATABASE_URL')
SECRET_KEY = config('SECRET_KEY')
DEBUG = config('DEBUG', default=False, cast=bool)
```
