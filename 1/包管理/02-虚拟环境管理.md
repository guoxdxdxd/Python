# 虚拟环境管理

## 1. 虚拟环境简介

虚拟环境是 Python 项目隔离的重要工具，它允许每个项目使用独立的 Python 包和依赖，避免不同项目之间的包版本冲突。

### 1.1 为什么需要虚拟环境
- **依赖隔离**：不同项目可以使用不同版本的包
- **避免冲突**：防止全局包污染
- **便于部署**：确保项目依赖的一致性
- **团队协作**：统一开发环境

### 1.2 虚拟环境工具对比
| 工具 | 特点 | 适用场景 |
|------|------|----------|
| venv | Python 内置，简单易用 | 基础项目隔离 |
| virtualenv | 功能丰富，兼容性好 | 复杂项目需求 |
| conda | 跨语言，包管理强大 | 数据科学项目 |
| Poetry | 现代工具，依赖管理完善 | 现代 Python 项目 |
| uv | 极速包管理，Rust 编写 | 高性能项目开发 |

## 2. venv（Python 内置）

### 2.1 创建虚拟环境
```bash
# 创建虚拟环境
python -m venv myenv

# 指定 Python 版本
python3.11 -m venv myenv

# 创建时安装 pip
python -m venv --system-site-packages myenv

# 创建时升级 pip
python -m venv --upgrade-deps myenv
```

### 2.2 激活和退出
```bash
# 激活虚拟环境
# macOS/Linux:
source myenv/bin/activate

# Windows:
myenv\Scripts\activate

# 验证激活
which python  # macOS/Linux
where python  # Windows

# 退出虚拟环境
deactivate
```

### 2.3 虚拟环境管理
```bash
# 查看虚拟环境信息
python -c "import sys; print(sys.prefix)"

# 查看已安装的包
pip list

# 生成 requirements.txt
pip freeze > requirements.txt

# 从 requirements.txt 安装
pip install -r requirements.txt
```

## 3. virtualenv

### 3.1 安装和使用
```bash
# 安装 virtualenv
pip install virtualenv

# 创建虚拟环境
virtualenv myenv

# 指定 Python 版本
virtualenv -p python3.11 myenv

# 创建时安装包
virtualenv --system-site-packages myenv

# 创建时升级 pip
virtualenv --upgrade-deps myenv
```

### 3.2 高级功能
```bash
# 创建时指定包
virtualenv --extra-search-dir /path/to/packages myenv

# 创建时设置环境变量
virtualenv --setuptools myenv

# 创建时复制全局包
virtualenv --always-copy myenv
```

## 4. conda

### 4.1 安装 Miniconda
```bash
# 下载 Miniconda
# macOS:
curl -O https://repo.anaconda.com/miniconda/Miniconda3-latest-MacOSX-x86_64.sh
bash Miniconda3-latest-MacOSX-x86_64.sh

# Linux:
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh

```

### 4.2 conda 环境管理
```bash
# 创建环境
conda create -n myenv python=3.11

# 创建时安装包
conda create -n myenv python=3.11 numpy pandas

# 激活环境
conda activate myenv

# 退出环境
conda deactivate

# 列出环境
conda env list

# 删除环境
conda env remove -n myenv
```

### 4.3 conda 包管理
```bash
# 安装包
conda install numpy

# 从 conda-forge 安装
conda install -c conda-forge package_name

# 安装 pip 包
conda install pip
pip install package_name

# 导出环境
conda env export > environment.yml

# 从文件创建环境
conda env create -f environment.yml
```

## 6. uv（极速包管理工具）

### 6.1 uv 简介
uv 是一个用 Rust 编写的极速 Python 包管理工具，由 Astral 公司开发。它提供了比传统 pip 快 10-100 倍的包安装速度，同时集成了虚拟环境管理、依赖解析等功能。

### 6.2 uv 的特点
- **极速安装**：比 pip 快 10-100 倍
- **内置虚拟环境**：自动管理虚拟环境
- **依赖解析**：智能的依赖冲突解决
- **兼容 pip**：完全兼容 pip 和 requirements.txt
- **跨平台**：支持 Windows、macOS、Linux
- **Rust 编写**：高性能和内存安全

### 6.3 安装 uv

#### macOS 和 Linux
```bash
# 使用 curl 安装
curl -LsSf https://astral.sh/uv/install.sh | sh

# 或使用 Homebrew (macOS)
brew install uv

# 或使用 pip 安装
pip install uv
```

#### Windows
```powershell
# 使用 PowerShell 安装
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# 或使用 pip 安装
pip install uv
```

#### 验证安装
```bash
uv --version
```

### 6.4 uv 基本使用

#### 创建和管理虚拟环境
```bash
# 创建虚拟环境
uv venv

# 创建指定 Python 版本的虚拟环境
uv venv --python 3.11

# 创建指定名称的虚拟环境
uv venv myenv

# 激活虚拟环境
source .venv/bin/activate  # macOS/Linux
.venv\Scripts\activate     # Windows

# 退出虚拟环境
deactivate
```

#### 包管理
```bash
# 安装包
uv pip install requests

# 安装多个包
uv pip install requests numpy pandas

# 从 requirements.txt 安装
uv pip install -r requirements.txt

# 安装开发依赖
uv pip install -r requirements-dev.txt

# 卸载包
uv pip uninstall requests

# 列出已安装的包
uv pip list

# 显示包信息
uv pip show requests
```

#### 项目初始化
```bash
# 初始化新项目
uv init my-project

# 进入项目目录
cd my-project

# 添加依赖
uv add requests

# 添加开发依赖
uv add --dev pytest black

# 安装项目依赖
uv sync

# 运行项目
uv run python main.py
```

### 6.6 pyproject.toml 配置
```toml

    "pytest>=7.0.0",
    "black>=23.0.0",
    "flake8>=6.0.0",
]
```

## 8. 自动化脚本

### 8.1 环境设置脚本
```bash
#!/bin/bash
# setup.sh

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
source venv/bin/activate

# 升级 pip
pip install --upgrade pip

# 安装依赖
pip install -r requirements.txt

# 安装开发依赖
pip install -r requirements-dev.txt

echo "环境设置完成！"
echo "使用 'source venv/bin/activate' 激活环境"
```

### 8.2 Windows 批处理脚本
```batch
@echo off
REM setup.bat

REM 创建虚拟环境
python -m venv venv

REM 激活虚拟环境
call venv\Scripts\activate

REM 升级 pip
python -m pip install --upgrade pip

REM 安装依赖
pip install -r requirements.txt

REM 安装开发依赖
pip install -r requirements-dev.txt

echo 环境设置完成！
echo 使用 'venv\Scripts\activate' 激活环境
pause
```

### 8.3 uv 环境设置脚本

## 9. 多环境管理

### 9.1 使用 pyenv
```bash
# 安装 pyenv
curl https://pyenv.run | bash

# 配置环境变量
echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.zshrc
echo 'command -v pyenv >/dev/null || export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.zshrc
echo 'eval "$(pyenv init -)"' >> ~/.zshrc

# 安装 Python 版本
pyenv install 3.11.5
pyenv install 3.12.0

# 设置全局版本
pyenv global 3.11.5

# 为项目设置版本
pyenv local 3.12.0
```

### 9.2 使用 direnv
```bash
# 安装 direnv
brew install direnv  # macOS
# 或
sudo apt install direnv  # Ubuntu

# 配置 shell
echo 'eval "$(direnv hook zsh)"' >> ~/.zshrc

# 创建 .envrc 文件
echo "source venv/bin/activate" > .envrc
direnv allow
```

## 10. 故障排除

### 10.1 常见问题
```bash
# 虚拟环境激活失败
# 检查路径是否正确
ls -la venv/bin/activate

# 权限问题
chmod +x venv/bin/activate

# Python 版本不匹配
python --version
which python
```

### 10.2 环境冲突
```bash
# 清理环境
deactivate
rm -rf venv
python -m venv venv
source venv/bin/activate

# 重新安装依赖
pip install -r requirements.txt
```

### 10.3 包版本冲突
```bash
# 查看冲突
pip check

# 强制重新安装
pip install --force-reinstall package_name

# 使用约束文件
pip install -c constraints.txt package_name
```
